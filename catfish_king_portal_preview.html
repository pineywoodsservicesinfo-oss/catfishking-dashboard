The Problem & Solution

Current: Paper & Email

  • 9 separate Excel files per store
  • Emails trickling in all week
  • Manual data entry and re-entry
  • No real-time visibility
  • Lost documents and attachments
  • ~30 min/day of administrative work
  • DataCache fees + paper costs

New: Unified Digital Portal

  • All modules in one system
  • Data entered once, flows everywhere
  • Corporate sees data in real-time
  • Organized document folders
  • Auto-calculations and validation
  • ~5 min/day for daily reports
  • You own the system forever

User Roles & Permissions

👤 Store Manager Role

  • Enter Daily Sales Report for their store only
  • Enter Daily Log for their store only
  • Enter Weekly Inventory for their store only
  • Enter Cash Audits for their store only
  • Upload documents to their store's folders
  • View historical data for their store only
  • Cannot see other stores' data

👔 Corporate/District Manager Role

  • View ALL stores' data in real-time
  • Run District Manager Report (consolidated)
  • Export any report to Excel/PDF
  • Access all document folders
  • Manage user accounts
  • Filter by date range across all stores

Project Overview

🎯 Goal

Replace fragmented paper-and-email system with a unified digital portal for all 11 Catfish King locations.

⏱️ Timeline

~12 weeks total, delivered in 4 phases starting with a 3-week pilot at 1-2 locations.

💡 Key Feature

Auto-population: Enter data once in Daily Sales Report, it flows to Daily Log, Labor Projection, and District Report.

📊 Outcome

Corporate gets real-time visibility into any store's data, eliminating the "emails trickling in all week" problem.
