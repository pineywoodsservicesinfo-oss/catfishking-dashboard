## User Management

### Creating Store Manager Accounts

1. Login as Corporate Admin
2. Go to **Admin → Users**
3. Click **"Add User"**
4. Fill in:
   - Email: `storename@catfishking.com`
   - Role: Store Manager
   - Store: [Select from dropdown]
   - Temporary password
5. Click **"Create User"**
6. System sends welcome email with login instructions

### Role Definitions

| Role | Permissions | Typical Users |
|------|-------------|---------------|
| **Corporate** | View all stores, export reports, manage users | Clay, Executives |
| **District Manager** | View assigned stores, run District Report | Regional managers |
| **Store Manager** | Enter data for their store only | Store managers |
| **Admin** | Full system access | Joel (Piney Digital) |

### Password Reset

If manager forgets password:
1. Go to **Admin → Users**
2. Find user
3. Click **"Reset Password"**
4. Temporary password sent to email

## Daily Operations

### Corporate Dashboard Overview

**Overview Tab:**
- 14-day sales trend chart
- Today's submission status (green/red)
- Top performing stores
- Alerts for missing reports

**All Locations Tab:**
- Submission status per store
- Last report date
- Last net sales
- Quick links to store drill-down

**Exports Tab:**
- Date range selection
- Excel export (DataCache format)
- PDF export (formatted report)

### Monitoring Submissions

**Morning Check (9 AM):**
1. Dashboard shows overnight submissions
2. Red indicators = missing reports
3. Click store name → see details

**Weekly Review (Friday):**
1. Set date range (last 7 days)
2. Export to Excel
3. Review trends
4. Follow up on missing reports

### Running Reports

**District Manager Report:**
1. Go to **Reports → District**
2. Select month/year
3. View consolidated data:
   - Net sales (this year vs last year)
   - Labor %
   - COGS %
   - Cash over/short

**Custom Date Range:**
1. Go to **Reports → Custom**
2. Select start and end dates
3. Choose stores (or "All")
4. Export to Excel

## Data Validation

### Spot Checking

**Weekly:** Compare 2-3 stores:
- New system total vs DataCache export
- Should match within $0.01

**Red flags:**
- Consistently lower/higher totals
- Missing void entries
- Deposit totals off

### Handling Discrepancies

1. **Verify:** Check both systems for same date
2. **Document:** Screenshot differences
3. **Contact:** Reach out to Joel with details
4. **Resolution:** Usually data entry error or calculation issue

## Phase Rollout Strategy

### Phase 1 (Weeks 1-3): Pilot
- 1 store
- Daily check-ins
- Refine based on feedback

### Phase 2 (Weeks 4-7): Soft Launch
- Add 3-4 stores
- Weekly check-ins
- Managers train managers (peer learning)

### Phase 3 (Weeks 8-10): Full Rollout
- Remaining 6-7 stores
- Bi-weekly check-ins
- Standardize on new system

### Phase 4 (Weeks 11-12): Transition
- Parallel with DataCache
- Compare final month
- Switch to new system only

### Go/No-Go Criteria

**Proceed to next phase if:**
- ≥90% on-time submission rate
- ≤5% data discrepancies
- Manager satisfaction ≥7/10
- No critical system issues

**Delay if:**
- Major technical issues
- Manager resistance
- Data integrity problems
